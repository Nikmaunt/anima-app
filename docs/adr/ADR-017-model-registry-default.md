# ADR-017: Реестр моделей и модель по умолчанию — Qwen2.5-1.5B, модель = данные

Дата: 2026-07-18 (v0.5 Фаза 1B/1C/1D). Статус: принято.
Заменяет «одна модель на телефон» из ADR-010 и снимает костыль ADR-014.

## Контекст

v0.4 жёстко связывал GEMMA-тир с Gemma 3 1B: один файл в хранилище, EN-only
промпт, «существо пока говорит по-английски» (ADR-014). Ресёрч v5
(docs/model-matrix.md) показал: Gemma 3 1B **официально English-only**, при
этом существуют Apache-2.0 модели того же класса с нативным качеством всех
шести языков продукта и готовыми артефактами под наш рантайм.

## Решение

1. **Модель = данные.** `MindModelRegistry` (core/model) описывает известные
   артефакты: формат промпта (PLAIN/CHATML), стоп-токены, токен-бюджет,
   языки, лицензию, хинты имён файлов. Незнакомый файл получает честный
   fallback-спек (PLAIN, EN-only, UNKNOWN-лицензия). Движок (`GemmaMindEngine`)
   читает всё это из реестра; добавление модели — правка данных, не кода.
2. **Мультимодельное хранилище.** `MindModelStore` держит несколько файлов;
   `MindModelResolver` выбирает: явный выбор владельца → новейший
   пользовательский файл → pack-модель за RAM-гейтом. Экран «Разум»
   показывает установленные модели и переключает их.
3. **Модель по умолчанию для пака: Qwen2.5-1.5B-Instruct** (Apache 2.0,
   29 языков, готовые .task/.litertlm, замеры S25U: 34 tok/s CPU).
   Компромиссы и лимит пака 1.5 GB — docs/model-matrix.md §Выбор: в пак
   идёт int4-сборка (~1.1 GB; до её подтверждения слот может нести прежнюю
   Gemma, Qwen приходит через download/SAF — реестр уже понимает оба).
   Альтернативы: Qwen3-1.7B (когда litert-конверсия подтвердится),
   Gemma 4 E2B (премиум, download-only).
4. **Языковая маршрутизация (Фаза 1D).** `MindLanguageRouting.decide(язык
   интерфейса, тир, спек)`: модель говорит на языке UI → полностью нативный
   промпт (`MindVoice`: персона/тело/лейблы/тон на 6 языках); не говорит →
   английский ответ + честная плашка в UI; облако — всегда нативно.
   Извлечение фактов требует текст фактов на языке пользователя.
   Никакого перевода выхода модели не существует — только честный выбор.

## Последствия

+ ADR-014-костыль снят маршрутизацией, а не обещанием.
+ Смена дефолтной модели пака = замена файла в слоте + строка в реестре.
− Стоп-токены ChatML вычищаются на нашей стороне (StreamTrimmer) — у
  MediaPipe нет stop-token опции.
− Мультиязычное качество Qwen2.5 на живом SoC до S24-прогона — риск,
  закрытый бейк-офф харнессом (чеклист v5 §0/§0c).
- NANO-тир до верификации считается EN-only (плашка) — честность выше
  оптимизма.
