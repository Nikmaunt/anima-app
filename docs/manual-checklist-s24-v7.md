# Ручной чеклист S24 — v0.7 (2026-07-24)

Прогоняется владельцем на живом Galaxy S24 (8 GB, Exynos 2400). База — v6
(рядом); здесь v7-дельта и перенесённые незакрытые пункты. Отмечай
✅/❌/⚠️ прямо в файле.

## §0. Бейк-офф + гейт int4-Qwen (перенос из v6, НЕ закрыт)

Как v6 §0 (артефакт из `tools/qwen-int4/convert.sh` — сначала конверсия,
блокер среды v0.6: WSL/C:; после хост-ребута повторить). Плюс v7:

8. **НОВОЕ: сравнение движков на ОДНОЙ модели.** Debug-сборка →
   Settings → «Для разработчика» → тумблер «Движок LiteRT-LM»
   (default OFF; ADR-020). На том же установленном `.litertlm`:
   - [ ] OFF (tasks-genai): 5 реплик RU — ток/с, first-chunk, RAM-пик: ____
   - [ ] ON (LiteRT-LM, CPU): те же 5 реплик — ток/с, first-chunk,
         RAM-пик, качество не хуже: ____
   - [ ] Извлечение фактов работает на обоих (предложение факта после
         «запомни: …»).
   - [ ] Выключить флаг — следующая реплика снова через tasks-genai
         (без перезапуска процесса допустим один releaseResources).
   Это гейт «критериев смены дефолта» ADR-020 — данные, не решение.
