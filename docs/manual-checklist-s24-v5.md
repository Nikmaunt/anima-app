# Ручной чеклист S24 — v0.5 (2026-07-18)

Прогоняется владельцем на живом Galaxy S24 (8 GB, Exynos 2400). Автотесты
покрывают всё, что могут; здесь — только то, что доказывается лишь живым
телефоном. Прошлые версии: v2–v4 рядом. Отмечай ✅/❌/⚠️ прямо в файле.

## §0. Первый разговор — теперь ×2 модели (бейк-офф)

Цель: сравнить прежнюю Gemma 3 1B и новую дефолтную Qwen2.5-1.5B на живом
SoC, а не на эмуляторе. Харнесс уже в репо (`MindBakeoffHarness`).

1. Скачай оба артефакта (litert-community: `Gemma3-1B-IT` int4 `.task`,
   `Qwen2.5-1.5B-Instruct` `.task`).
2. `adb push <файлы> /sdcard/Android/data/app.anima.core.mind.test/files/bakeoff/`
3. `gradlew :core:mind:connectedDebugAndroidTest --tests "*MindBakeoffHarness*"`
4. `adb pull /sdcard/Android/data/app.anima.core.mind.test/files/bakeoff-report.json`
5. Зафиксируй здесь: load-время, first-chunk мс, ток/с (chars/totalMs·~3),
   RAM-пик (`adb shell dumpsys meminfo` во время прогона):
   - Gemma 3 1B: ____
   - Qwen2.5-1.5B: ____
6. Вердикт: Qwen2.5 пригодна как дефолт пака? (скорость ≥15 ток/с,
   без OOM на 8 GB, ответы связные) — если ❌, реестр остаётся, дефолт
   пака откатывается на Gemma (правка одной строки ADR-017).

## §0c. Качество RU-разговора глазами носителя

UI на русском, установлена Qwen2.5-1.5B, облако ВЫКЛ:
1. Первый разговор: 10 реплик по-русски («как ты?», «что ты чувствуешь?»,
   «запомни: меня зовут Ник», «что помнишь обо мне?»).
2. Оценить: (а) отвечает по-русски без английских вкраплений; (б) падежи/
   род согласованы, нет кальки; (в) персона держится («я — этот телефон»);
   (г) извлечённый факт показан ПО-РУССКИ и осмысленно.
3. Переключи модель на Gemma 3 1B (экран «Разум»): плашка «отвечает
   по-английски» появилась? Ответ пришёл на EN, не ломаном RU?
4. Повтори (1) на JA, если есть силы — хотя бы 3 реплики (ромадзи-вкрапления
   и кана-мешанина = ❌).

## §1. Мультимодельность вживую

1. Экран «Разум»: обе модели видны, размеры/языки/лицензии корректны.
2. Переключение Gemma↔Qwen без перезапуска приложения; следующий ответ
   приходит от новой модели (стиль заметно меняется).
3. Удаление одной модели: чат жив, резолвер упал на оставшуюся.
4. Удаление ВСЕХ моделей: «разум спит», существо живо, никаких крэшей.

## §2. Облачные пресеты (нужен любой бесплатный ключ)

1. Чип Groq (или OpenRouter) → поля заполнились → вставь ключ → «Check key»
   → «The key works».
2. Испорти ключ (последний символ) → «The provider rejected this key».
3. Режим полёта → «Could not reach the provider».
4. Включи облако, задай RU-локаль: ответ по-русски, лейбл CLOUD виден.

## §3. Погодное чувство (у S24 барометр ЕСТЬ)

1. День с меняющейся погодой: открой приложение утром/днём/вечером
   (набирается лог). При падении давления (идёт фронт) существо в разговоре
   упоминает «кости ноют» без подсказки? (спроси «как ты?»)
2. Быстрая проверка: `adb shell dumpsys sensorservice | grep -i pressure` —
   сенсор виден приложению без разрешений.

## §4. Вечерний ритуал + капсула

1. После 21:00: жест/кнопка прощания видна; попрощайся — тёплая реплика,
   существо сворачивается; вторая попытка в тот же вечер — жеста уже нет.
2. НЕ прощайся сутки — никакого упрёка нигде (главный инвариант!).
3. Напиши капсулу «на 7 дней»; проверь `adb shell date -s` НЕ используем
   (сломает журнал) — вместо этого временно поменяй горизонт в
   debug-сборке или дождись срока на живом устройстве. Письмо пришло —
   существо вручает его один раз, повторно не показывает.
4. Экспорт души → импорт на чистую установку: капсулы переехали
   (payload v2), старый бэкап v1 импортируется без ошибок.

## §5. Локализация смоук

1. Системная локаль RU → всё приложение по-русски, ни одной EN-строки
   (пройди все экраны). Повтори бегло на PL.
2. Псевдолокаль en-XA (debug): ничего не обрезано на Home/Mind/Rest.
3. ar-XB: RTL не ломает существо и чат.
4. TTS: RU-голос офлайн есть → говорит по-русски; голоса нет → молчит,
   не переключается на сетевой.
