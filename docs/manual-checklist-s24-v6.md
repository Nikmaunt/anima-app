# Ручной чеклист S24 — v0.6 (2026-07-19)

Прогоняется владельцем на живом Galaxy S24 (8 GB, Exynos 2400). Автотесты
покрывают всё, что могут; здесь — только то, что доказывается лишь живым
телефоном. Прошлые версии рядом (v2–v5). Отмечай ✅/❌/⚠️ прямо в файле.

## §0. Бейк-офф ×2 модели — теперь с настоящим int4-Qwen

Цель: сравнить Gemma 3 1B и НАШ int4-артефакт Qwen2.5-1.5B (ADR-018) на
живом SoC. Если конверсия ещё не выполнена — сначала
`bash tools/qwen-int4/convert.sh` на Linux/WSL2 (CPU, ~1 час) и сверь
sha256 с MANIFEST.txt.

1. Файлы: litert-community `Gemma3-1B-IT` int4 `.task` +
   `qwen2.5-1.5b-instruct-int4.litertlm` из конверсии.
2. `adb push <файлы> /sdcard/Android/data/app.anima.core.mind.test/files/bakeoff/`
3. `gradlew :core:mind:connectedDebugAndroidTest` (класс MindBakeoffHarness)
4. `adb pull .../bakeoff-report.json`
5. Зафиксируй: load-время, first-chunk мс, ток/с, RAM-пик (dumpsys meminfo):
   - Gemma 3 1B int4: ____
   - Qwen2.5-1.5B int4 (наш): ____
6. КРИТИЧЕСКОЕ (граница смоука эмулятора): `.litertlm` вообще читается
   tasks-genai 0.10.35 на живом устройстве? Если ❌ — матрица ADR-018,
   строка 2 (пустой слот + first-run download НЕ спасает — эскалация:
   пробовать litertlm-android 0.14.0, отдельный ADR).
7. Вердикт пригодности как дефолта пака: скорость ≥15 ток/с, без OOM,
   ответы связные на RU — если ✅, пак несёт int4-Qwen (ADR-018 строка 1).

## §0b. Ночь обоев (ТРЕТИЙ перенос — v4 → v5 → v6, так и не прогнан)

Live wallpaper установлен, телефон на зарядке всю ночь. Утром:
Settings → Battery → «за ночь» ≤1–2%? AOD не дрался с обоями?
Если и в этот раз не прогнано — в v0.7 честно вычеркнуть фичу из
store-листинга до доказательства.

## §0c. Качество RU-разговора носителем — теперь на НАШЕМ int4

Как v5 §0c (10 реплик RU, падежи/персона/факт по-русски), но на артефакте
из §0. int4-квантизация могла задеть многоязычие сильнее, чем q8 — если
русский «поплыл» относительно прошлого прогона q8: зафиксируй примеры и
попробуй `dynamic_int4_block32`-вариант (качество выше, +5% размера;
переключается одной переменной в convert.sh).

## §0d. Апгрейд с реальными данными v0.5 → v0.6

На телефоне, где прожита v0.5 (реальные факты/разговоры/капсулы):
1. `adb install -r` подписанного release-APK v0.6 ПОВЕРХ (не удаляя).
2. Открыть: существо то же, имя то же, чат-история на месте, факты на
   месте, удержанные капсулы держатся (дневник → счётчик писем).
3. Diary → письмо себе → неделя. Настройки → лицензии открываются.
4. Вечером (после 21:00): луна прощания видна; сказать «спокойной ночи» —
   реплика пришла, луна ушла, второй раз за вечер не предлагает.
5. FLAG_SECURE: попытка скриншота на карточке пришедшей капсулы и на
   экране души — системный отказ (если тумблер в Settings не включён).

## §0e. Подписанный release: R8-поведение вживую

Debug-сборки не ловят R8/minify-регрессии; эмуляторный GMD гоняет debug.
1. `gradlew :app:assembleRelease` (с ../anima-keys) →
   `apksigner verify --print-certs` → CN=Anima Upload.
2. Чистая установка release-APK: онбординг → выбор тела → имя → чат с
   паком/без — ни одного крэша ClassNotFound/обфускации (смотреть
   `adb logcat -s AndroidRuntime` весь прогон).
3. Импорт души из v0.5-бэкапа (.backup с парольной фразой) на release —
   расшифровка и факты живы (R8 не съел crypto/serialization пути).
4. Report-механизм: long-press по реплике существа → «пожаловаться» —
   реплика исчезла из треда и после перезапуска не вернулась.

## §0f. Фолды/планшеты (если под рукой Fold/Flip или планшет)

1. На развёрнутом Fold (или планшете в ландшафте): Home в две панели —
   существо слева целиком, чат справа; ничего не обрезано.
2. Сложить/разложить на лету: состояние чата не теряется, существо не
   перезапускает анимацию с рывком.
3. Тема Material You: иконка приложения — монохромный силуэт орба в
   themed-режиме лончера (Android 13+).

## §1. Остальное

Прогнать быстрые проверки v5 §1 (виджет, шорткаты, голос, обои-превью,
языковой переключатель per-app) — регрессий после v0.6 быть не должно;
плюс: беззвучный режим → реплики существа заметно короче и «шёпотом»,
озвучка молчит даже при включённом голосе.
