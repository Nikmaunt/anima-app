# Что проверить на физическом S24 — v1.1.1

По приоритету. Каждый пункт — что сделать, что должно быть, и что значит,
если не так.

Сборка: `app/build/outputs/apk/debug/app-debug.apk` этого дерева.

```
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

⚠️ Перед проверкой обоев и виджета удалите тестовые пакеты, если они есть:
`adb uninstall app.anima.feature.wallpaper.test` — иначе в системном списке
обоев окажутся ДВЕ «Anima», и вторая рисует чёрный экран (см. `phase6`, §6.6).

---

## 1. Ваша душа цела 🔴 ПЕРВЫМ ДЕЛОМ

Этот прогон ввёл миграцию, которая умеет переписывать тело. Она **не должна**
трогать ваше — но проверить это надо вам, до всего остального.

1. Установите сборку и запустите приложение.
2. Настройки → **«Открыть паспорт»**.
3. Сверьте:
   - **портрет** — то же существо, что было вчера;
   - **имя** — ваше;
   - **«Вылупилось»** — прежняя дата;
   - **Геном** — восемь символов, две группы.
4. Home → **Душа**: счётчики «дней / разговоров / воспоминаний / кормёжек»
   не должны обнулиться.
5. Home → **Дневник**: записи на месте.

Машинная проверка того же, если хотите наверняка:

```
adb shell run-as app.anima ls files/identity-backup
```

- **`No such file or directory` — правильный ответ.** Значит миграция
  посмотрела на вашу душу и ничего не тронула: она вылуплена сборкой, которая
  тело предлагала выбрать, а выбранное тело не переписывается никогда.
- Если каталог **есть** — миграция что-то поправила. Тогда:

```
adb shell run-as app.anima cat files/crash/identity-repair.txt
adb shell run-as app.anima cat files/identity-backup/identity-*.json
```

Первый файл скажет, что именно было исправлено; второй хранит значения **до**
правки. Восстановить можно по нему. То же видно на экране: Настройки →
журнал падений.

> Проверено на эмуляторе с пятидневной душой: каталог не создался, тело не
> изменилось. Но на эмуляторе не ваша душа.

## 2. Живые обои, дневной кадр 🔴

Единственное, что этот прогон **не смог** проверить.

1. Долгое нажатие на домашнем экране → Обои → Живые обои → **Anima**.
   - Ожидание: в списке рядом с названием **яйцо с трещиной**, а не серая
     заглушка «сломанная картинка». Если заглушка — миниатюра не подхватилась.
2. Установите. Дождитесь дня (или переведите часы на 14:00).
3. Смотрите на **подписи лаунчера** — дату, имена приложений.
   - **Хорошо:** подписи тёмные и читаются на светлом фоне обоев.
   - **Плохо:** подписи белые и почти не видны. Значит One UI не честит
     `HINT_SUPPORTS_DARK_TEXT`. Скажите — фон дневного кадра придётся затемнить.
4. Ночью (после 22:00) существо должно спать на почти чёрном фоне.
5. Побудьте на домашнем экране полчаса и посмотрите расход батареи Anima в
   настройках Samsung. Обещание — 0 fps в покое; на эмуляторе это недоказуемо.

## 3. Виджет на домашнем экране 🟠

За двенадцать прогонов виджет **ни разу не ставился на лаунчер** — Android не
даёт сделать это из консоли. Кадры отрисованы и просмотрены, само размещение —
нет.

1. Долгое нажатие на домашнем экране → Виджеты → Anima → перетащите.
2. Ожидание: ваше существо, **прозрачный фон** (обои просвечивают), нет рамки
   и нет карточки.
3. Тап открывает приложение.
4. Поставьте телефон на зарядку — виджет должен смениться на «ест».
5. Если после свежей установки виджет **пустой, но нажимается** — это не
   поломка, это путь «личность ещё не прочитана». Через секунду он наполнится.

## 4. Экран Души — вёрстка 🟠

Здесь была правка, которую **не удалось переснять**: эмулятор завис.

Home → **Душа**. Смотрите на ряд кнопок под счётчиками.

- **Хорошо:** «Экспорт души», «Наша история…», «Открытка» стоят в ряд или
  переносятся на вторую строку целыми словами.
- **Плохо:** «Открытка» стоит **столбиком по одной букве**. Это тот самый
  дефект, который правка чинила, и значит она не сработала.

Там же: подпись четвёртого счётчика — «кормёжек» — не должна переноситься.

Повторите при **Настройки → Размер шрифта = максимальный**.

## 5. Онбординг с нуля 🟠

**Осторожно: это сотрёт существо на телефоне.** Делайте только на запасном
аппарате или после экспорта души.

```
adb shell pm clear app.anima
```

1. Яйцо → «Познакомиться».
2. Ожидание: тело и имя **появляются сами**. Выбора нет, поля ввода имени нет.
3. Дальше — предложение поставить виджет. Кнопка «Добавить виджет» должна
   открыть системный диалог One UI.
4. Проверьте, что имя — произносимое, 4–7 букв, латиницей.
5. Настройки → паспорт → имя можно поменять.

---

## 6. Иконка и splash 🟡

1. Посмотрите на иконку Anima в лаунчере: **яйцо с трещиной**, не светящийся
   шар.
2. Включите тематические иконки One UI — монохромная версия то же яйцо.
3. Запустите приложение и посмотрите на первый кадр: splash — та же иконка.
   Никакого чужого существа быть не должно.

## 7. Мотылёк 🟡

Только если ваше тело — мотылёк, или из любопытства через контактный лист
`docs/design/v11/contact/`.

Вопрос простой: **это мотылёк или это жук?** Ответ нужен словами. Прогон
считает, что «не бабочка» получилось, а «мотылёк» — не до конца.

## 8. Оттенки 🟡

Настройки → паспорт → **«Оттенки»** (раздел назывался «Формы»).

1. Наденьте открытый оттенок.
2. Ожидание: **акцент всего приложения** уезжает вслед за надетым оттенком —
   кнопки, заголовки, фон. Не только превью.
3. Закрытые оттенки показывают условие («7 дней вместе»), а не обратный отсчёт.

## 9. Складной экран 🟡

Если под рукой есть Fold — раскройте в **портрете**. Двух колонок быть не
должно: одна колонка всегда, пока экран выше, чем шире. В ландшафте — две.

## 10. Чат за тумблером ⚪

Настройки → «Экспериментальный чат» → включить → открыть.

Без установленного разума ожидается: одна фраза существа и **одна** кнопка,
ведущая на экран Разума. Поля ввода быть не должно.
